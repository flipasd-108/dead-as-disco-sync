# Dead as Disco Sync: дизайн

Окно выглядит как обычная программа Windows 11: tkinter/ttk с темой [Sun Valley](https://github.com/rdbende/Sun-Valley-ttk-theme) (`sv-ttk`). Своих цветов, шрифтов и размеров нет, всё берётся из темы. Светлая или тёмная тема выбирается по настройке Windows (`AppsUseLightTheme`), в тёмной теме заголовок окна тоже тёмный.

## Раскладка

- Сверху строка ввода: подпись, поле, «Обзор...», «Старт» (акцентная кнопка, `Accent.TButton`) и под ней серая подсказка в две строки.
- По центру таблица песен (`Treeview`): песня, темп, статус, когда. Новые песни сверху, во время анализа в статусе виден текущий шаг.
- Под таблицей рамка «Настройки для игры» выбранной песни: переключатель вариантов А/Б (если их два), четыре поля только для чтения (их можно выделить и скопировать), строка про подрезку и кнопки «Папка в игре», «Показать WAV», «Лог».
- Внизу строка статуса: состояние папки игры, «Папка игры...», «Готовые WAV».

## Правила

- Нестандартных виджетов, карточек, цветных плашек и крупных шрифтов не добавлять: если нужен новый элемент, берётся стандартный ttk-виджет.
- Отступы 12 от края окна и между блоками, 8 между кнопками в ряду.
- Окно знает о масштабе экрана (`SetProcessDpiAwareness`), поэтому текст чёткий и не мелкий на экранах с масштабированием.
