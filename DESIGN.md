# Dead as Disco Sync: дизайн

Стиль «Жёлтый постер»: от ключевого арта игры (неоново-жёлтый, тёмный фон, фиолетовый неон). Окно на customtkinter: плоская заливка и скругления, без свечений и градиентов.

## Цвета

| Токен     | Значение  | Где                                         |
| --------- | --------- | ------------------------------------------- |
| bg        | `#121019` | фон окна, поля ввода, плашки цифр           |
| panel     | `#1E1A2B` | карточки                                    |
| line      | `#332C49` | рамки, второстепенные кнопки                |
| text      | `#FAF7EC` | основной текст                              |
| dim       | `#A39DB8` | подписи, статусы                            |
| accent    | `#FFE600` | заголовок, кнопка «Старт», цифры результата |
| on_accent | `#121019` | текст на жёлтом                             |
| ok        | `#7DD3FC` | «Добавлено в игру», успешные статусы        |
| error     | `#FF5C7A` | ошибки                                      |

Жёлтый только на одном главном действии и на результате: если жёлтого много, он перестаёт вести взгляд.

## Шрифты

- Заголовки, кнопка «Старт», цифры: Bahnschrift SemiBold (есть в Windows 10/11), 16–26.
- Текст и подписи: Segoe UI, 11–13.

## Размеры

- Отступы от края окна 24, внутри карточек 16, между блоками 16.
- Скругление карточек 14, кнопок и плашек 10.
- Высота поля ввода и кнопок в строке ввода 40.
